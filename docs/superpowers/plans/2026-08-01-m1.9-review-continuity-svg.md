# M1.9 Review Continuity and Static SVG Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Preserve one Lavish conversation across plan revisions and render the dependency graph as deterministic inline SVG.

**Architecture:** Keep immutable revision snapshots while introducing one stable `review.html` path per mission. Generate a small static SVG from the already-validated dependency DAG with no external runtime or new package.

**Tech Stack:** TypeScript 5.9, Node.js 24.18+, node:test, existing MNFS CLI and Lavish adapter.

## Global Constraints

- Canonical runtime is Ubuntu on WSL2; browser remains on Windows.
- Do not add Mermaid, a CDN, Graphviz, browser layout runtime or another npm dependency.
- SQLite and structured plan JSON remain authoritative.
- HTML/SVG output must be deterministic and self-contained.
- Use TDD and run `npm run verify` before acceptance.
- M1 remains planning-only; do not implement M2 workers or adapters.
