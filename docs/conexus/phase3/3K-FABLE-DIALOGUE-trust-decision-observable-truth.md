## 4. Global Maximum attack

Central decision attacked: **context-local truth surfaces + shared visual grammar** vs credible alternatives.

1. **Trust/Approval Center (Alt B).** Would centralize four decision families with four distinct semantic owners (Builder Change, PAR ApprovalRequest, Release/Promotion, I&A). Any shared center needs either a unifying vocabulary (violates 3G-R1 non-unification and C-013 UI=projection — the exact defect class this program spent 3G/3F closing) or a lossless multi-family surface, which is just the context-local surfaces relocated behind an extra navigation hop. It eliminates no named failure class and adds one. Rejection is correct, and the reopen trigger (real cross-Project operator workload → aggregate **projection**, never authority) keeps the future additive: an aggregate read-only pending-work projection can be layered later over the same owner facts without dismantling anything. No structural dead end.
2. **Universal frontend FSM.** The frontend must render ~8 frozen owner-local state spaces. A universal FSM requires a lossy mapping — precisely forbidden equivalences §7.2. Per-family projectors are essential complexity (distinct owners are a 3G-R1 fact, not a UI choice); the shared **visual grammar** removes the accidental part (inconsistent look/interaction) without touching meaning. This is the correct essential/accidental split.
3. **Chat-only decisions (Alt C) / raw console (Alt D).** Both fail already-approved law (3F-03 mechanical card; Package A progressive disclosure). Correctly rejected.
4. **Local-maximum probe.** Predictable retrofits checked: fifth decision family (app-origin approvals → Decision Loop per 3F-03 §23, reopen trigger present); cross-run approval workload (reopen trigger present); notification consumer (C-007/C-013 trigger preserved). None requires dismantling context-local surfaces.

**Verdict: Global Maximum sustained.** The rejection of Trust Center / Approval Center / universal frontend FSM is the smallest sustainable design over the closed authorities.
