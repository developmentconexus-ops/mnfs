# Contributing to Conexus OS

Read `AGENTS.md`, then select the task pack from `docs/INDEX.md`. Keep one current authority per meaning, preserve accepted owner boundaries, and avoid permanent handoff/review artifacts.

Use an Ubuntu WSL2 Linux-filesystem worktree. Create a focused branch and PR. Define proof before implementation; show negative controls can fire when meaningful; run focused checks and then:

```bash
npm ci
npm run verify
```

Framework, dependency, and live-integration claims require current primary documentation plus exact pinned source/configuration and proportionate Evidence. Research never becomes Product authority without an accepted decision.

Do not start 3M, ratify C-018, implement Product code, or perform production effects by inheritance from repository history.
