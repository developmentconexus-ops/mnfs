1. the canonical checkout is never Treehouse cwd;
2. every Attempt uses an independent Linux-owned source at the exact approved base commit;
3. execution sources have zero remotes, no alternates, no shared common directory and no hardlinked canonical objects;
4. Treehouse runs only with controlled HOME/XDG/config/hooks and the accepted binary/command boundary;
5. Domain state and matching versioned Events commit atomically;
6. composite keys preserve exact Track → Attempt → Run/Lease → Claim ancestry;
7. `LeaseActionRunner` records durable STARTED evidence before one external invocation;
8. an inconclusive started grant never triggers an automatic second `treehouse get`;
9. release remains conditional, idempotent and fenced by all internal and external identities;
10. dirty, ambiguous or unclassified work is preserved;
11. plain Recovery is read-only and never performs automatic repair;
12. M01 does not launch Pi, create production SEC-E1, complete Claims, issue Receipts or accept work.
