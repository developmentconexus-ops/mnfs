# ARR-S0 Host Capability Probe

This directory contains the deterministic implementation surface for the ARR-S0 Host Capability Probe.

Current authorization is limited to construction and deterministic tests. A real host probe is prohibited until a separate `GATE-S0-EXECUTE` Operator authorization binds the accepted contract, exact canonical commit and verification Evidence.

The harness must remain observation-only: no package installation, host configuration changes, candidate execution, runtime/environment selection, production Worker dispatch or M02 implementation.
