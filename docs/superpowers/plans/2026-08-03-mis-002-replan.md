# MIS-002 Schema v2 Replan Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reconcile canonical M2 coverage, accept `CAP-EXECUTION`, create and exact-hash approve a two-Milestone `MIS-002` schema-v2 Replan, and mechanically recalculate R0–R4 without implementing the M2 Worker.

**Architecture:** Keep product doctrine in the accepted Blueprint, roadmap, ADRs and MCRM; keep capability requirements and readiness in `CAP-EXECUTION/TRACEABILITY.json`; keep the Mission contract in the existing append-only SQLite/Lavish planning flow. Add a stable `SEC-E1` definition artifact, preserve revision 3 as an exact historical snapshot, and compute readiness from accepted documents plus the currently materialized contract rather than stale prose.

**Tech Stack:** Node.js 24.18+, TypeScript 5.9, SQLite-backed MNFS planning service, deterministic Markdown/JSON generators, Pi planning skill, Lavish browser review, GitHub Actions, Ubuntu WSL2.

## Global Constraints

- Canonical execution environment is Ubuntu WSL2 with the repository under the Linux filesystem.
- Historical `MIS-002` revision 3 must remain byte-for-byte identical: blob `6b79117fe66cd5c9c8142099828812f470ce20de`, content hash `sha256:f95ffded37af764e5f76775ec6bbdda69d5638246609451ce37bf524908cf8c1`.
- Never edit `.mnfs/missions/MIS-002/plan.json` manually; only `plan approve` may materialize a newer approved contract.
- New Mission content uses `schemaVersion: 2` and the exact previous approved hash.
- Mission, Milestone and Feature criteria remain separately decidable; no child-count aggregation.
- M2 remains a fixed deterministic one-Worker slice with no arbitrary task text.
- `SEC-E1` denies network and credentials, allows only X0/X1 effects, and fails closed.
- The AS-02 effective run hash is provenance only; the Mission binds to the stable `SEC-E1` definition hash.
- Worker completion is never Claim acceptance.
- No deciding criterion depends on Herdr, Observational Memory, `pi-link`, remote execution or an external observability backend.
- No M2 Worker implementation, dispatch, automatic approval, PR merge or M2 unblock occurs implicitly.
- Exact Operator gates in this plan must be honored literally.

async function validateHistoricalMission() {
  const historicalRel = '.mnfs/missions/MIS-002/history/revision-0003.json';
  const currentRel = '.mnfs/missions/MIS-002/plan.json';
  if (!await exists(root, historicalRel)) {
    errors.push(`Missing historical Mission contract: ${historicalRel}`);
    return;
  }

  const historicalText = await readFile(path.join(root, historicalRel), 'utf8');
  const historicalBlob = createHash('sha1')
    .update(`blob ${Buffer.byteLength(historicalText)}\0`)
    .update(historicalText)
    .digest('hex');
  const historical = JSON.parse(historicalText);

  if (historicalBlob !== '6b79117fe66cd5c9c8142099828812f470ce20de') {
    errors.push('Historical MIS-002 revision 3 bytes changed.');
  }
  if (
    historical.revision !== 3 ||
    historical.contentHash !== 'sha256:f95ffded37af764e5f76775ec6bbdda69d5638246609451ce37bf524908cf8c1'
  ) {
    errors.push('Historical MIS-002 revision 3 identity changed.');
  }

  if (!await exists(root, currentRel)) return;
  const currentText = await readFile(path.join(root, currentRel), 'utf8');
  const current = JSON.parse(currentText);
  if (current.revision === 3 && currentText !== historicalText) {
    errors.push('Current MIS-002 revision 3 differs from its immutable historical snapshot.');
  }
  if (current.revision > 3 && current.content?.schemaVersion !== 2) {
    errors.push('A post-revision-3 MIS-002 contract must use schemaVersion 2.');
  }
}

- [ ] **Step 4: Implement the narrow validator and hasher**

Create `scripts/sec-e1-policy.mjs` exporting:

```js
import { createHash } from 'node:crypto';

const EXPECTED_TOOLS = ['bash', 'read', 'write', 'edit', 'grep', 'find', 'ls'];
const SYMBOLIC_SCOPE = /^[A-Z][A-Z0-9_]*$/u;

export function hashSecE1Bytes(bytes) {
  return `sha256:${createHash('sha256').update(bytes).digest('hex')}`;
}

export function validateSecE1(value) {
  const errors = [];
  if (!value || typeof value !== 'object' || Array.isArray(value)) return ['SEC-E1 must be an object.'];
  if (value.schemaVersion !== 1) errors.push('schemaVersion must equal 1.');
  if (value.id !== 'SEC-E1') errors.push('id must equal SEC-E1.');
  if (value.environmentRef !== 'ENV-E1') errors.push('environmentRef must equal ENV-E1.');
  if (value.sandboxRuntime?.package !== '@anthropic-ai/sandbox-runtime') errors.push('sandbox package mismatch.');
  if (value.sandboxRuntime?.version !== '0.0.67') errors.push('sandbox version must equal 0.0.67.');
  if (value.sandboxRuntime?.failClosed !== true) errors.push('sandbox must fail closed.');
  if (value.sandboxRuntime?.weakerNestedSandbox !== false) errors.push('weaker nested sandbox must remain disabled.');
  if (value.sandboxRuntime?.weakerNetworkIsolation !== false) errors.push('weaker network isolation must remain disabled.');
  if (JSON.stringify(value.tools) !== JSON.stringify(EXPECTED_TOOLS)) errors.push('tools must equal the reviewed seven-tool inventory.');

  for (const [name, scopes] of Object.entries({
    allowWriteScopes: value.filesystem?.allowWriteScopes,
    denyReadScopes: value.filesystem?.denyReadScopes,
    denyWriteScopes: value.filesystem?.denyWriteScopes,
  })) {
    if (!Array.isArray(scopes) || scopes.some((scope) => typeof scope !== 'string' || !SYMBOLIC_SCOPE.test(scope))) {
      errors.push(`${name} must contain symbolic scopes only.`);
    }
  }

  if (value.filesystem?.pathResolution !== 'ATTEMPT_BOUND_REALPATH') errors.push('pathResolution mismatch.');
  if (value.network?.mode !== 'DENY_ALL') errors.push('network mode must equal DENY_ALL.');
  if (value.network?.allowLocalBinding !== false) errors.push('local binding must remain denied.');
  if (!Array.isArray(value.network?.allowUnixSockets) || value.network.allowUnixSockets.length !== 0) errors.push('Unix socket allowlist must remain empty.');
  if (value.credentials?.mode !== 'NONE') errors.push('credential mode must equal NONE.');
  if (value.effects?.maximumClass !== 'X1' || value.effects?.productionEffects !== false) errors.push('effects must remain X1-or-lower and non-production.');
  if (value.process?.shell !== false) errors.push('shell must remain false.');
  if (value.process?.inheritHostEnvironment !== false) errors.push('host environment inheritance must remain disabled.');
  if (value.process?.childrenInheritRestrictions !== true) errors.push('child restrictions must propagate.');
  if (value.hashing?.definitionHash !== 'SHA256_EXACT_UTF8_BYTES') errors.push('definition hashing contract mismatch.');
  if (value.hashing?.effectivePolicyHash !== 'SHA256_COMPILED_RUN_POLICY') errors.push('effective hashing contract mismatch.');
  if (!Array.isArray(value.evidence) || !value.evidence.includes('ACCEPTANCE-AS-02-LOCAL-PI-SANDBOX-WSL2')) errors.push('accepted AS-02 evidence reference is required.');
  return errors;
}
```
